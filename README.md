# 🏠 Arduino Voice Controlled Home Automation

## 📌 Overview

This project presents a **Voice Controlled Home Automation System** developed using **Arduino Uno**, **HC-05 Bluetooth Module**, and **Relay Modules**. The system allows users to control home appliances through voice commands sent from an Android smartphone.

The project was developed as a Major Project for the Bachelor of Technology degree in Electronics and Communication Engineering at IIIT Bhopal.

## 🏗 System Architecture

---

## 🎙 Supported Voice Commands

| Command        | Action          |
| -------------- | --------------- |
| turn on light  | Light ON        |
| turn off light | Light OFF       |
| turn on fan    | Fan ON          |
| turn off fan   | Fan OFF         |
| turn on TV     | TV ON           |
| turn off TV    | TV OFF          |
| turn on pump   | Pump ON         |
| turn off pump  | Pump OFF        |
| turn on all    | All Devices ON  |
| turn off all   | All Devices OFF |

## ⚙ Installation

### 1. Clone Repository

```bash
git clone https://github.com/Arpeet-Bhaisare/Arduino-voice-controlled-home-automation.git
```

### 2. Open Arduino IDE

Open:

```text
voice_home_automation.ino
```

### 3. Connect Hardware

* Arduino Uno
* HC-05 Bluetooth Module
* Relay Module
* LCD Display

### 4. Upload Code

Select:

```text
Tools → Board → Arduino Uno
```

Upload the sketch.

---

## 📱 Mobile Application Setup

1. Install Bluetooth Voice Control App.
2. Enable Bluetooth.
3. Pair HC-05 Module.
4. Connect from App.
5. Speak supported commands.
